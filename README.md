# Task Manager

Jednoduchý terminálový správce úkolů napsaný v Pythonu.  
Program běží v cyklu, ve kterém uživatel vybírá jednotlivé akce.  
Úkoly jsou ukládány v paměti programu jako seznam (list).

## Požadavky
- Python 3.6+

## Funkce
- Přidat nový úkol  
- Zobrazit všechny úkoly  
- Odstranit úkol  
- Konec programu

## Ukázka použití
```
Vyberte možnost (1-4): 1
Zadejte název úkolu: Nakoupit
Zadejte popis úkolu: Zajít do obchodu a nakoupit potraviny
Úkol byl přidán.

Vyberte možnost (1-4): 2
1. Nakoupit - Zajít do obchodu a nakoupit potraviny

Vyberte možnost (1-4): 3
Zadejte číslo úkolu, který chcete smazat: 1
Úkol byl smazán.

Vyberte možnost (1-4): 4
Program ukončen.
```
